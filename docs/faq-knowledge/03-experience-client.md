# Expérience client au QR code

## client-scan
topics: scanner, scan, qr code, table, client, utiliser, comment, service à table, guest, use, table service
fr: Le client scanne le QR code du restaurant, consulte les catégories et ouvre les fiches plats depuis la table. L’équipe en salle reste disponible pour conseiller et accompagner le choix.
en: The guest scans the restaurant’s QR code, browses categories and opens dish pages from the table. The dining-room team remains available to guide the choice.

## client-sans-application
topics: application, appli, app, télécharger, téléchargement, installer, sans application, navigateur, download, install, browser
fr: Le client n’a pas besoin de télécharger d’application. Le menu Vistaire s’ouvre directement dans le navigateur mobile après le scan du QR code, comme une page web.
en: The guest does not need to download an app. The Vistaire menu opens directly in the mobile browser after scanning the QR code, like a web page.

## client-sans-compte
topics: compte, inscription, connexion, créer un compte, s'inscrire, account, sign up, login
fr: Le client n’a pas besoin de créer un compte : l’objectif est de consulter la carte rapidement à table.
en: The guest does not need to create an account: the goal is to browse the menu quickly at the table.

## client-wifi
topics: wi-fi, wifi, internet, réseau, connexion, données mobiles, network, mobile data
fr: Le client n’a pas besoin du Wi-Fi du restaurant. Le menu s’ouvre avec la connexion mobile du client, comme n’importe quelle page web.
en: The guest does not need the restaurant’s Wi-Fi. The menu opens through the guest’s mobile connection, like any web page.

## client-appareils
topics: iphone, android, téléphone, smartphone, mobile, appareil, compatible, compatibilité, safari, chrome, phone, device, compatibility
fr: La carte web est conçue pour les navigateurs mobiles modernes, sur iPhone comme sur Android. Les options AR dépendent ensuite de l’appareil du client.
en: The web menu is designed for modern mobile browsers, on iPhone and Android. AR options then depend on the guest’s device.

## client-sans-smartphone
topics: sans smartphone, pas de téléphone, papier, menu papier, tablette, no smartphone, paper menu, tablet
fr: Si un client n’a pas de smartphone, le restaurant peut conserver un menu papier ou proposer une tablette. Vistaire ne remplace pas l’accueil humain.
en: If a guest has no smartphone, the restaurant can keep printed menus or offer a tablet. Vistaire does not replace human hospitality.

## client-qr-par-table
topics: qr par table, combien de qr, zone, plusieurs qr, un qr, one qr per table, how many qr
fr: Un QR code par table ou par zone peut fonctionner selon le service. L’important est que le scan ouvre toujours la même carte soignée.
en: One QR code per table or per zone can work depending on service. What matters is that the scan always opens the same carefully made menu.
