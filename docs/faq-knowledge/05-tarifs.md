## tarifs-remplacement-3d

fr: Un nouveau plat nécessitant une nouvelle production 3D est facturé, même s’il remplace un ancien plat. La correction d’un modèle 3D défectueux imputable à Vistaire n’est pas une nouvelle production.
en: A new dish that requires a new 3D production is billable, even when it replaces an older dish. A correction to a defective 3D model attributable to Vistaire is not a new production.

## tarifs-conditions
